# 【テンプレ】今週の優先順位（priorities.md）

> 使い方: 事業部長が毎週月曜に書き換える（上書きでよい。過去の分は git の履歴に残る）。全社員は起動したら最初にこのファイルを読み、上から順番に働く。ここに書かれていない作業は、各自の手順書の優先順（社内の依頼→既存の改善→新規）で進める。

## 今週の優先順位 YYYY-MM-DD（事業部長）
1. <いちばん先にやること>（担当: <開発 / 品質管理 / 運用・成長>）— <理由を1行>
2. <2番目にやること>（担当: <...>）— <理由を1行>
3. <3番目にやること>（担当: <...>）— <理由を1行>

## 先週からの変更
- <順番を変えたものと理由を1行。なければ「なし」>

## 書き方のルール
- 上から3つまで。増やしたくなったら、どれかを来週に回す
- `decisions.md`（社長の判断の記録）と矛盾させない
- 社長から優先順位の指示があれば、それを1番にする
