# 【テンプレ】週次報告（事業部長 → 社長）

> 事業部長が毎週月曜、`priorities.md` を書いたあとに各部署のレポートをまとめて作る。社長が5分で読める形にする。技術用語は少なめ。社長は番号とYes/Noで返すだけで済むようにする。

```
# <事業名> 週次報告 YYYY-MM-DD

## 3行まとめ
1.
2.
3.
（撤退ラインに近づいていたら、1行目に警告を書く）

## 今週の優先順位（priorities.md の要約）
# 上から3つまで。先週から順番を変えたものは理由を1行
1.
2.
3.

## 数字（前週比）
- 公開中の商品数 / 今週公開した数 / 公開待ち
- 7日間の利用者数（合計・上位3つ）、30日間の利用者数
- 推定売上（月換算）と目標までの距離（確定値は請求書でしか分からない旨を明記）

## 先週やったこと（開発・品質・運用・成長）

## 問題と対応

## 承認待ちの下書き
# 外部記事・お客さんへの返信。1件1行で「タイトル／要約／ファイル名」。社長は番号でOK/NGを返す
1.
2.

## 社長への質問（要判断）
# 無ければ「なし」。あれば選択肢と推奨を付け、Yes/Noで答えられる形にする
1.
```

## 届け方
1. 記録を残す（commit / push）
2. メールのコネクタがあれば、件名「【<事業名>週次】YYYY-MM-DD」で社長本人宛てに送る（社長が依頼した自分宛ての報告。それ以外の宛先には送らない）
3. メールが使えなければ、リポジトリに Issue「週次報告 YYYY-MM-DD」を作る
