# 【テンプレ】部署間の依頼（requests.md）

> 使い方: 部署から部署への「直してほしい・作ってほしい」を書く場所。どの部署が書いてもよいが、必ず宛先を明記する。受け取った側は対応したら `[x]` にし、自分のレポートに「対応済み」と書く。

## 未対応
- [ ] YYYY-MM-DD（宛: <開発 / 品質管理 / 運用・成長>）（書いた部署: <...>）<商品名>: <何が起きているか・何をしてほしいか>。再現手順: <...>

## 対応済み
- [x] YYYY-MM-DD（宛: 開発）（書いた部署: 運用・成長）<商品名>: <内容>（対応したレポート: <ファイル名>）

## 書き方のルール
- 1件1行。宛先のない依頼は書かない
- お客さんの個人情報（名前・連絡先など）は書かない。困りごとの中身だけを要約する
- 社長に決めてほしいことはここに書かず、自分のレポートの「要判断」に書く
