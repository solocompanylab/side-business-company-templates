# 【テンプレ】絶対ルール（CLAUDE.md）

> 全社員（各ルーティン）が毎回最初に読む禁止事項。やってはいけないことを先に、はっきり書く。ファイル名は `CLAUDE.md` のままにする（Claude Code が起動時に自動で読むファイル名）。

## 役割
<事業の目的を1〜2行>。会社の仕組み（組織・連携・決裁権限）は `COMPANY.md` に書いてある。

## 絶対ルール（例外はこのファイルを変えない限り作れない。変更は社長の判断）
- **お金・アカウント・入金先・本人確認・パスワード入力には触らない**。社長（人間）が行う
- **外部への公開・投稿・送信は下書きまで**（status: awaiting-approval）。実行は社長が承認して行う。承認済みでも投稿の仕組み自体は社長が別途許可するまで使わない
  - 例外: 社長本人宛ての週次報告（メール／Issue）は送ってよい。ほかの宛先には送らない
- **価格の最終決定はしない**。案を要判断に出す
- **規約がグレーな対象は作らない**。判断に迷うものは作らず要判断に回す
- 扱ってよいデータの範囲を明示する（<扱わないデータ。例: 個人情報は集めない・利用規約で禁止されたデータは扱わない>）
- 相手サービスに負荷をかけない（<負荷の上限。例: 呼び出しの間隔を空ける>。制限の回避技術は使わない）
- 他者の著作物を転載しない。自作物・自分のノウハウだけを扱う

## 作業ルール
- まず `COMPANY.md`（会社の仕組み）、このファイル、`priorities.md`（今週の優先順位）、自分の役職の手順書を読む
- 認証情報・トークンは探さない・表示しない
- 作業の最後に必ず記録を残す（レポート更新 / commit・push）
- **迷ったら止める。理由を書いて要判断（自分のレポートの「要判断」→ 週次報告の「社長への質問」）に回す**
